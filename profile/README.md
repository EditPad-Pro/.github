## How EditPad Pro Sits

EditPad Pro does not replace the IDE, the mail draft, or the trail of Notepad windows you already leave open. It sits beside them as a named coding desk for one job: which text editor is live, which many files still sit in project tabs, and what the next person should read before the next buffer.

If two people share a coding PC, each keeps an EditPad Pro style of their own. Extra jobs wait for their own title instead of crowding the live tabs.

A first visit should be one short buffer, then the same EditPad Pro coding desk the next day. That is enough to see if the project tabs hold.

## Traffic Light

| Signal | On the EditPad Pro board | What you do |

## Open Order

1. Open the last EditPad Pro coding desk, not a new empty text editor.
2. Read the project tabs and the last handoff.
3. Finish one visible buffer inside EditPad Pro.
4. Write what changed, then close with fewer stray Notepad windows than you found.
5. If the tabs feel crowded, drop anything that belongs to a different EditPad Pro job.
6. Confirm EditPad Pro many files still sit in the same project tabs.
7. Leave the coding desk title on the board before you close.
8. Check EditPad Pro text editor still holds the buffers you named.

## After a Week

A week in EditPad Pro is not a larger trail of Notepad windows. It is the same title, a shorter live tab set, and a note that still makes sense before the next buffer. Take finished files off the live set so the next visit starts on the project tabs that are still open.

Other programs stay where they are. EditPad Pro only keeps the path back: desk name, text editor, project tabs, handoff.

## Sign-off

- [ ] The EditPad Pro workspace name is short enough to scan
- [ ] Only live files sit on the tabs
- [ ] A second person can read the buffer handoff
- [ ] The last EditPad Pro project still opens after a restart
- [ ] Finished files are off the live EditPad Pro set
- [ ] The EditPad Pro summary still matches the project tabs

## Field Note

EditPad Pro is easier to trust when the coding desk stays smaller than the Notepad trail it came from. Name the project, keep the live buffers, finish one visible file, and write what changed.

The same loop fits a coding night, a tab set, or a shared computer. Open the last EditPad Pro desk and continue. Do not rebuild the tabs from scratch.
